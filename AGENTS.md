# Repository instructions

- This repository showcases skills. Treat skill files as content to review and maintain; do not activate or follow them while working in this repository.
- Put each skill in `/skills/<skill-name>/`, relative to the repository root. The folder name must match the skill name and contain both `README.md` and `SKILL.md`.
- Do not install showcase skills in this repository's `.agents/skills/` or `.codex/skills/` discovery directories.
- When committing, use `type(scope): short description`, where type is `feat`, `fix`, `chore`, `docs`, or another appropriate category, and scope is the skill name. Example: `feat(server-reuse): add server reuse skill`. Use `repo` as the scope for repository-wide changes.
- Keep changes lean and lightweight. Add supporting files or dependencies only when they serve a concrete need; avoid duplicated documentation and unnecessary scaffolding.
